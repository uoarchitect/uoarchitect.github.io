# UO Architect

An isometric house planner for Ultima Online. Lay a foundation, build up to four floors, place walls, stairs, doors
and decorations, then save your design or export it as a JSON file to share.

**Use it:** https://uoarchitect.github.io/

## Unofficial fan tool
UO Architect is an unofficial, non-commercial fan project. It is **not affiliated with, endorsed by or sponsored by
Electronic Arts or Broadsword**. *Ultima Online* and related names are trademarks of their respective owners.

## No game art or music is included
This repository and website contain **no Ultima Online artwork, music or data files**. The first time you open the
page you point it at **your own Ultima Online folder**. The art library (and a few music tracks) are then built
**on your computer, in your browser**, and kept in your browser's local storage. Nothing is uploaded anywhere.
Saved and exported designs contain only item numbers, positions and hues, never game art.

## Using it
* Works best in desktop **Chrome or Edge**. The first visit asks you to select your UO folder once.
* Click the info (i) button inside the app for the controls and shortcuts.
* Five save slots are kept in your browser. **Export** gives a JSON file you can share.

## Privacy
There is no server, no account and no tracking. Everything stays in your browser.
